## Objectif
Une seule opération GPU à la fois par pipeline (verrou interne, `OSAllocatedUnfairLock`) : l'enrôlement (vjp) marque la pipeline occupée, une synthèse ou un chargement concurrent est refusé (`busy`) ; transitions d'état atomiques, jeton de génération pour ignorer une Task périmée ; enrôlement dans `withRandomState` ; la démo désactive Play/Load/modèle pendant l'enrôlement.

**Porte** : test d'intégration `EnrollInferenceExclusionTests` (`enrollVoice` 50 époques ∥ `synthesizeStreaming`) : 20/20 exécutions sans blocage (timeout 120 s), synthèse refusée `busy` en < 1 s ou exécutée après ; rouge sans le correctif (blocage ou chevauchement détecté) ; test de stress TSan (2 × `loadModel`, `unload` pendant un stream, synthèse pendant enrôlement) : 0 alerte, états finaux cohérents 10/10 ; suite complète verte.

Si la porte n'est pas atteinte : rien n'est livré ; `blocked` avec une question fermée (trois échecs sur la même erreur ⇒ ASK).
