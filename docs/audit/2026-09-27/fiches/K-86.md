# K-86 — TTS : voix `.pt` de `tts-4b`, graine de ZeroVoice, troncature signalée en streaming, shards sans index

- **Source** : entrées de #590 (planificateur, 2026-10-01 et 2026-10-03) :
  - `tts-4b` (pack original Mistral) annonce « 0 voices loaded » : ses voix sont des `.pt`
    (`VoxtralVoicePresets.swift:48`, téléchargées par `ttsDownloadGlobs`, `VoxtralModelDownloader.swift:236`) que le
    chargeur ne lit pas (défaut antérieur à l'audit) ;
  - « le CLI ignore `--seed` avec `-v` » : corrigé pour `-v`/`--voice` et `--blend` par `5e6625c2` (K-33) ; reste
    `--voice-xyz` (ZeroVoice), qui n'a pas de paramètre `seed` (`VoxtralCLI.swift:511`) ;
  - `lastSynthesisTruncated` n'est mis à jour que par les chemins batch (`VoxtralTTSPipeline.swift:294`, `:423`), pas
    par `synthesizeStreaming` ; le chemin streaming frame par frame n'a pas de test (`VoxtralTTSModeling.swift:706`) ;
  - chargement TTS sans index : repli codé en dur sur `model-0000{1,2}-of-00002` (`VoxtralTTSModelLoading.swift:135-147`).
- **Prérequis** : aucun (K-7, K-12, K-14 vérifiées) · **⛔ GATE** : non
- **Effort** : S-M · **Risque API publique** : aucun en signature (`synthesize(text:voiceCoordinate:seed:)` additif)
- **Cible** : `macos-gpu` · **Lot** : 4 · **Branche** : `claude/action-plan-skills-beta-wifgmu`
- **ASK liées** : aucune

## Objectif
Le pack `tts-4b` charge ses voix prédéfinies (ou refuse avec une erreur typée qui nomme le format), toutes les voies
du CLI appliquent la graine, la troncature est signalée aussi en streaming, et un dossier TTS à N shards sans index se
charge.

**Porte** :
- `VoxtralCLI tts -m tts-4b -v neutral_female` : « N voices loaded » avec N ≥ 1 et audio produit, **ou** erreur typée
  nommant le format `.pt` (jamais « 0 voices loaded » suivi d'une synthèse) ; test rouge avant ;
- `--voice-xyz 50,50,50 --seed 3` deux fois → `out_sha256` identiques ; `--seed 3` contre `--seed 4` → différents
  (rouge avant) ;
- test : `synthesizeStreaming` avec un plafond de frames atteint → `lastSynthesisTruncated == true` (rouge avant) ;
  test du chemin streaming frame par frame (codes identiques au batch à graine fixe, comme K-12) ;
- fixture « 3 shards sans index » → chargement complet, 0 clé manquante (`verify` de K-7), rouge avant.

## Étapes
1. Voix `.pt` : lire le format (archive PyTorch zip, tenseur bf16 `[T, 3072]`) ; soit un lecteur minimal sans
   dépendance Python, soit l'erreur typée et une note dans `docs/Weights.md` (le choix « lecteur » n'ajoute aucune
   dépendance : sinon, erreur typée).
2. ZeroVoice : paramètre `seed` additif, transmis depuis `--voice-xyz`.
3. `lastSynthesisTruncated` dans le chemin streaming ; test.
4. Shards : liste par motif `model-*-of-*.safetensors` triée, au lieu du repli à deux fichiers.
5. Journal (PLAN.md §7, log.md), commit `fix(K-86): …`, rapport.

  tourne (une seule charge GPU à la fois).
