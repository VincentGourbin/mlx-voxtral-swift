## Objectif
La CI prouve que les exécutables compilent et ne masque plus d'échec ; l'instrument de mesure est testé ; en `.mlx`,
le temps d'encodage a sa phase.

**Porte** :
- run CI vert qui construit en Release les trois schémas (`** BUILD SUCCEEDED **` × 3 dans le journal), sans
  `|| true`, actions sur Node ≥ 24, lignes `[K-` conservées, `check-demo-ffmpeg.sh` lancé ; nombre de `warning:`
  comparé à une base versionnée (échec si hausse) ;
- un échec volontaire (commit jetable) fait échouer la CI (rouge prouvé) ;
- tests de l'instrument : `unionLength`, somme des phases ≤ total, `lastPadFraction` et `streaming_pad_fraction` sur
  une séquence fixe ; rouges sur mutation ;
- `bench stt --backend mlx` (mini-3b-8bit, C-moyen EN) : `phases_ms.encode` présent et
  `audio + encode + prefill` = `ttft_ms` ± 5 % ; sorties (`out_sha256`) et `step_ms_p50` inchangés contre
  `BASE-mini-3b-8bit-mlx-c_moyen_en` (21,32 ms ± 3 %) ;
- script `Scripts/run-guarded-tests.sh` (tests `TEST_RUNNER_*` sur le Mac) avec la liste des 40 tests gardés, et
  son résultat recopié.

## Étapes
1. `ci.yml` ; preuve rouge/vert.
2. Tests de `BenchCommand` (fonctions pures extraites si besoin).
3. Phase `encode` en `.mlx` : `eval` des embeddings audio avant le préfill, sous un `ProfilerPhase` dédié (aucun
