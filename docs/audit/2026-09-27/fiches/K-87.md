# K-87 — CLI et chargement : défaut `.auto` exercé par le CLI, hors ligne en `.auto`, erreurs de config non avalées

- **Source** : entrées de #590 (planificateur, 2026-10-03) :
  - seul `bench --backend auto` exerce le défaut public : `transcribe` et `chat` n'acceptent que `mlx` ou `hybrid`
    (`VoxtralCLI.swift:188`, `:299`) ;
  - passe hors ligne en `.auto` avec l'encodeur Core ML en cache : l'échec du téléchargement de l'encodeur est
    rattrapé (`VoxtralPipeline.swift:334-339`) et le contrôle hors ligne de K-10 n'a porté que sur `.mlx` ;
  - `loadRealtimeConfig` (`VoxtralRealtimeModelLoading.swift:72`) : un `try?` avale un `config.json` mlx illisible dès
    qu'un `params.json` existe ;
  - `profile run --output` échoue si le dossier parent n'existe pas (`ProfileCommand.swift`).
- **Prérequis** : K-10, K-25 (vérifiées) · **⛔ GATE** : non
- **Effort** : S · **Risque API publique** : aucun (CLI additif ; la bibliothèque ne change pas de défaut)
- **Cible** : `macos-gpu` · **Lot** : 4 · **Branche** : `claude/action-plan-skills-beta-wifgmu`
- **ASK liées** : aucune (le choix du défaut `.auto`/`.mlx` reste ASK-6 / K-42)

## Objectif
Le CLI sait exercer le défaut public, le mode hors ligne est prouvé pour les deux backends, et une configuration
illisible lève au lieu d'être remplacée en silence.

**Porte** :
- `VoxtralCLI transcribe -b auto` et `chat -b auto` acceptés ; sur C-court EN, `out_sha256` égal à celui de
  `bench stt --backend auto` (mini-3b-8bit) ;
- mode avion (ou réseau coupé par `networksetup`) avec modèle et encodeur Core ML en cache : `transcribe -b auto`
  réussit, 0 octet réseau (`nettop`) ; encodeur absent du cache : repli sur `.mlx` gardé (comportement public
  inchangé, décision de l'agent du 2026-10-10 : une erreur changerait le défaut `.auto` des consommateurs), annoncé
  par un log `os.Logger` de niveau `notice` hors `VoxtralDebug` ; test unitaire sur le choix du chemin et l'annonce ;
- fixture Realtime « `config.json` au format mlx illisible (JSON invalide, ou schéma mlx reconnu mais incomplet) +
  `params.json` » → erreur typée nommant le fichier (rouge avant) ; le `config.json` au format transformers du dépôt
  Mistral d'origine reste sauté au profit de `params.json` (K-9) : `RealtimeOriginalRepoTests` vert, non-régression ;
- `profile run --output <dossier inexistant>/x.json` crée le dossier (rouge avant).
