## Objectif
Référence mesurée du chemin STT à la révision courante (révision de mlx-swift-lm notée) : phases, préfill et décodage, TTFT, pics, WER, pour les modèles × backends × clips du protocole ; occupation GPU réelle du préfill (Metal System Trace + `ioreg`) ; verdict chiffré sur Small 4 bits à budget 32 Go.

**Porte** : A/A ≤ 3 % sur 2 passes pour chaque ligne ; une ligne `BENCHMARKS.md` par (modèle ∈ {mini-3b-4bit, mini-3b-8bit, mini-3b, small-4bit} × backend ∈ {.mlx, .auto} × clip ∈ {C-court EN, C-moyen EN, C-moyen FR, C-long}) avec la révision résolue et le WER ; occupation GPU du préfill Mini et Small consignée par les deux instruments (écart noté) ; small-4bit, 8 min d'audio : pic `phys_footprint` mesuré ≤ 24 Go (marge d'un Mac 32 Go), sinon verdict « non supporté sur 32 Go » écrit dans `docs/knowledge/decisions/small-32gb.md` ; chat : une ligne `BENCHMARKS.md` par backend ∈ {.mlx, .auto} pour mini-3b-8bit sur C-moyen EN × 4 questions fixes (greedy), avec `ttft_ms` de chaque question et tok/s (référence de K-49 et K-70).

Si l'A/A dépasse 3 % : ne pas enregistrer de baseline ; chercher la source de bruit (piège 8, 11, 19), refaire, sinon `blocked`.

## Étapes
1. Préparer : `git fetch origin && git checkout claude/action-plan-skills-beta-wifgmu && git pull --ff-only` ; lire `CLAUDE.md` s'il existe (K-17), cette fiche, `docs/audit/2026-09-27/PLAN.md` §0 et §5 (règles, corpus, commandes) et le constat source dans le rapport cité.
2. Construire : `xcodebuild -scheme VoxtralCLI -configuration Release -derivedDataPath .build/xcode -destination 'platform=macOS' build` → `** BUILD SUCCEEDED **` ; binaire noté `$CLI` = `.build/xcode/Build/Products/Release/VoxtralCLI`.
3. Avant toute mesure : `~/.claude/skills/mlx-swift-audit/scripts/machine-check.sh $CLI --cooldown 120 --procs 'Voxtral.*|FluxForge.*'` → aucune ligne `KO` ; noter la ligne `INFO process le plus gourmand`.
4. Pour chaque ligne : `$CLI bench stt --model <m> --backend <b> --input <clip> --passes 2 --warmup 1 --cooldown 120 --tag BASE` ; `$CLI eval …` pour le WER.
5. Metal System Trace : `xcrun xctrace record --template 'Metal System Trace' --launch -- $CLI bench stt … --passes 1` (préfill C-moyen, Mini et Small) + `ioreg -r -c AGXAccelerator` échantillonné.
5 bis. Chat (référence de K-49 et K-70) : `$CLI bench chat --model mini-3b-8bit --backend <mlx|auto> --input docs/examples/fluxforge_long_en_6bit.wav --questions docs/eval/chat-questions.json --passes 2 --warmup 1 --cooldown 120 --tag BASE`.
6. Small 4 bits sur 8 min d'audio (`ffmpeg -t 480` de C-long) : relever `peak_footprint_mb`.
7. Journal : entrée `## K-34 — … — <date> — validée|bloquée|retirée` dans `docs/audit/2026-09-27/PLAN.md` §7 et dans `docs/knowledge/log.md` ; chaque ligne `BENCH`/`EVAL` recopiée telle quelle dans `BENCHMARKS.md` (jamais de modification d'une ligne existante).
8. Commit `docs(K-34): …` sur `claude/action-plan-skills-beta-wifgmu` ; entrée de journal dans `docs/audit/2026-09-27/PLAN.md` §7.
