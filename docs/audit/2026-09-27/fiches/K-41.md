## Objectif
L'attention du codec ne matérialise plus de tenseurs (B, H, T, T) : calcul par blocs de 128 à 256 requêtes sur les clés [début − W, fin), exact puisque les entrées masquées valent exp(−1e9) = 0 ; `dist`, ALiBi et masques calculés une fois par étage.

**Porte** : forme d'onde |Δ|max ≤ 1e-4 contre l'actuel sur 3 textes (court, 60 s, long) ; pic `phys_footprint` du décodage long ≤ poids + 1 Go (contre ≥ 10 Go attendus aujourd'hui) ; décodage court ±5 % (A/B/B/A).
