## Objectif
Deux enrôlements à graine égale donnent les mêmes codes ; un enrôlement interrompu reprend à l'identique depuis son dernier point de contrôle (paramètres, moments d'Adam, température, époque, meilleur instantané, état RNG) ; la garde de divergence de #44 est protégée par des tests ; la démo a un bouton Annuler.

**Porte** : 2 enrôlements de 200 époques, même graine → codes `[T, 37]` identiques ; graines différentes → différents ; arrêt à 2 500 / 5 000 puis reprise → codes finaux identiques bit à bit au run continu ; surcoût de sauvegarde ≤ 5 % du temps total (dans le bruit) ; 3 tests (NaN à l'époque 0 → `EnrollmentDivergedError` ; NaN à l'époque k → codes du meilleur pas ; annulation → `CancellationError`) rouges sans la garde, verts avec.

Si la porte n'est pas atteinte : rien n'est livré ; `blocked` avec une question fermée.
