## Objectif
Les packs décidés par ASK-22 sont produits de façon reproductible (recette, révision source épinglée), publiés avec sidecar SHA-256 et carte (licence, parité), vérifiés au téléchargement (K-6) et référencés par les profils ; les packs tiers retenus (ASK-16) sont épinglés par révision + SHA-256.

**Porte** : pour chaque pack : SHA-256 publiés et vérifiés au téléchargement (test) ; parité : WER ≤ bf16 + 0,3 pt (STT, Realtime) ; TTS : couverture ASR ≥ 99 % et écoute contre bf16 (ASK-13) ; campagne de packs mixtes TTS : couverture ≥ 6 bits − 0,5 pt, 0 `maxFrames` sur le long FR (3 graines), fr/s ≥ 0,9 × le 4 bits, sinon non publiée ; carte sans exemple `transformers` erroné ; `docs/Weights.md` à jour.

Si la porte n'est pas atteinte : consigner l'écart dans la décision ; `blocked` si une valeur manque.
