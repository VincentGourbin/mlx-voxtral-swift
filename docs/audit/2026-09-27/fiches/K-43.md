## Objectif
Chaque chunk ne décode que [contexte gauche L + nouveaux codes] (codec causal à champ récepteur borné : convolutions causales, transposées tronquées, fenêtres 2-16) et jette les échantillons du contexte.

**Porte** : forme d'onde concaténée du streaming = batch (|Δ|max ≤ 1e-4) sur 3 textes × 3 graines ; temps de décodage par chunk constant ±20 % du chunk 1 au chunk 200 ; RTF streaming du texte long ≤ RTF batch + 5 %.

Si la porte n'est pas atteinte : le code est retiré, la fiche passe « retirée » avec la mesure (un rejet documenté vaut une technique retenue).
