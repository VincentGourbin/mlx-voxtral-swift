## Objectif
Chaque profil Realtime a une ligne mesurée (ms/pas p50/p90 contre le budget temps réel de 80 ms, latence au premier jeton texte, pic, WER) ; la largeur 8 bits est mesurée seulement si K-80 (ou l'assainisseur voxmlx) l'a rendue chargeable.

**Porte** : profils `4bit-fast|lean`, `16bit-fast|lean` mesurés (A/A ≤ 3 %, WER) ; `step_ms_p90` < 80 ms sur la machine de référence pour chaque profil `fast` ; 8 bits : pack chargé avec `verify: [.all]` (0 clé en écart) et WER 8 bits ≤ WER 4 bits sur C-moyen, sinon « non disponible » documenté ; une ligne `References.md` par profil (K-82).

Si la porte n'est pas atteinte : consigner l'écart dans la décision ; `blocked` si une valeur manque.
