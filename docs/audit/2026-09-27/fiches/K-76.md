## Objectif
Un type par pipeline, `static let all` + `named(_:)`, chaque champ = un bouton **déjà existant** (v0 : poids, backend, `MemoryOptimizationConfig`, `maxTokens`, `temperature`, `topP`, `repetitionPenalty`, retard Realtime, `maxFrames`/`cfgAlpha`/`flowSteps`, réglages d'enrôlement) ; les champs v1 (dtype, `cacheLimit`, KV 8 bits, tranche, résidence) s'ajoutent fiche par fiche quand leur bouton existe et est mesuré ; CLI `voxtral references` et `--reference <id>` sur `transcribe`, `realtime`, `tts`, `enroll`, `bench`.

**Porte** : `$CLI references` liste 6 profils STT Mini, 6 STT Small, 4 Realtime (4/16 × fast/lean), 6 TTS (4/6/16 × fast/lean, 6 bits déclaré hors standard) et 2 enrôlement, avec pour chacun `weights: <repo> (<octets>)` ; test : appliquer un profil produit exactement la configuration explicite équivalente (égalité des `Configuration`) ; `$CLI transcribe C-court EN --reference 8bit-fast` = même sortie greedy que les options explicites ; aucun profil v0 n'utilise un préréglage à fenêtre KV ; `VoxtralTTSSynthesisManager` charge le modèle demandé (test).

Si la porte n'est pas atteinte : rien n'est livré ; `blocked` avec une question fermée.
